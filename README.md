# Fresh Brownie — Static Website

A responsive, single-page static website based on the supplied brownie poster.

## Files
- `index.html` — complete website
- `assets/brownie-poster.jpg` — supplied poster image

## Static hosting
Upload the contents of this folder to any static host such as GitHub Pages, Netlify, Vercel static hosting, or an S3/CloudFront setup.

The website has no backend and no build step.
